# 上下文管理器

## 功能
帮助用户管理对话上下文，将编辑器选中的文本、终端输出、数据文件等内容组织到对话中。

## 工作流程

### 1. 检测选中内容
- 检查当前编辑器是否有文本选中
- 检查终端是否有输出被选中
- 确认内容的类型（代码、数据、日志、配置、文档等）

### 2. 添加到上下文
- 将选中的内容作为参考信息添加到当前对话
- 自动识别内容格式：
  - CSV → 解析为表格数据
  - JSON → 结构化展示
  - 日志 → 按级别分类
  - Markdown → 渲染展示
  - 代码 → 识别语言

### 3. 上下文管理
- 支持多条上下文片段的累积
- 用户可以随时说"查看上下文"查看当前积累的所有片段
- 用户可以随时说"清空上下文"清除所有片段
- 用户可以随时说"复制上下文"导出所有上下文

### 4. 智能建议
根据上下文内容类型，自动建议下一步操作：
- 数据 → 建议分析、可视化、导出
- 日志 → 建议排查、过滤、统计
- 代码 → 建议解释、优化、重构
- 配置 → 建议检查、对比、修改

## 交互示例

用户："把这个CSV数据加进去"
→ 识别选中内容为 CSV，解析为表格，展示概要，询问需要什么分析

用户："add to context"
→ 将当前选中内容添加到对话上下文，显示已添加的摘要

用户："查看上下文"
→ 列出所有已添加的上下文片段，每个片段显示类型和摘要

用户："清空"
→ 清除所有上下文片段
