将当前编辑器中选中的文本或终端输出添加到对话上下文中。

**操作步骤：**
1. 首先确认用户当前是否有文本被选中（检查编辑器选择或终端选择）
2. 如果有选中文本，将其作为上下文信息添加到当前对话中
3. 总结选中的内容类型（代码/数据/日志/配置等）和关键信息
4. 询问用户接下来想要对这些内容做什么操作（分析/解释/修改/对比等）

**如果用户没有选中任何文本：**
- 提示用户先在编辑器或终端中选中文本
- 告知用户可以使用 `Ctrl+I` 快捷键快速将选中代码带入内联对话
- 或者使用右键菜单中的 "Add to Chat" 选项

**快捷操作提示：**
- `Ctrl+I` — 选中代码后直接打开内联对话
- `Ctrl+Shift+I` — 选中代码后解释
- 右键菜单 → "Add to Chat" / "Explain with CodeBuddy"
- 本命令 `/add-to-chat:add` — 将选中内容添加到对话上下文
